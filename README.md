# vuepage

The active application is the Vue 3 frontend and Express API in [`vue-app/`](./vue-app/). User account country determines the wallet and game-provider currency: India uses INR, Pakistan uses PKR, and existing Nepal accounts use NPR. The user-facing currency label is `Rs.` for INR and NPR, and `PKR` for PKR.
